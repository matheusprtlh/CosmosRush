# Cosmos Rush

Jogo de plataforma 2D em pixel art. Explore Terra, Marte e Lua, administre o oxigênio e reúna quatro cristais para decolar na nave final.

Abra `project.godot` no Godot 4.7 (versão configurada no projeto) e execute a cena principal.

| Ação | Teclado |
| --- | --- |
| Mover | A/D ou setas esquerda/direita |
| Pular | W, Espaço ou Enter |
| Pausar ou continuar | Esc |

Leia o [GDD](Documentacao/Cosmos_Rush_GDD.md) para consultar as mecânicas e a sequência das fases.
